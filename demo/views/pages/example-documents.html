A form that reads the file you upload.

Review a lease by uploading it. One AI Document copies its key clauses into the form word for word, and checks every word of the copy against the lease. Another writes a summary for the property manager, and a third translates the lease into Spanish for the tenant. You check them before you save.

  1. You upload a leaseA PDF, a Word document, a text file, or a scan or photo of it. Download a sample lease from the form if you don't have one.
  2. ConvertedThe UAG identifies the file from its bytes and reads it as a PDF or as text, with converter plugins for Word and Excel.
  3. Copied and checkedThe extract plugin asks the model for the clauses, then compares the copy with the lease's text. A copy that differs is retried, then flagged.
  4. Summarized and translatedThe analyze plugin writes about the lease as the form's instructions ask; translate puts it into the language the form designer picked. Every result streams its progress and is yours to edit.

Generated, then checked.

Exact words

The clauses are compared with the lease's own text. Missing, changed or added words lower the score; below the form's minimum, the result is flagged and the differences are listed.

Into your own field

An AI Document can write into a field of the form: HTML for a rich-text editor, Markdown otherwise. It asks before it replaces something you wrote.

Plugins, not prompts in code

What the AI does is a document plugin installed on the UAG. The form designer picks one in the form builder and writes the instructions there; Build shows the settings.

Add it to your app.

The AI Document is a UAG feature, @formio/uag-extras/features/ai-document: the UAG serves its component with @formio/uag-js. It uploads to the form's own storage, posts the file references to the UAG's {form}/document/process, shows the streamed progress and the result, and keeps both in the submission: never the file's bytes.

  • It sends the signed-in user's own Form.io token, so the UAG reads the files with their permissions.
  • In the developer portal, set the project's custom JavaScript and CSS to the UAG's /uag-js/portal.js and /uag-js/portal.css to build with it.
  • The formio/uag-documents image carries the extract, analyze and translate plugins and the Word and Excel converter.
  • A process of your own is one file: build Translate yourself, step by step.
