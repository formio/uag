Getting Started

Run the UAG in your own environment.

The UAG is one container that sits beside Form.io. Start against a free project on Form.io's hosted platform, or self-host everything on your own infrastructure, from a laptop to an air-gapped data center.

Create a free project

Sign up at portal.form.io and create a project. Its API endpoint looks like https://yourproject.form.io.

Make a form visible to agents

Build or open a form, and add the tag uag under Settings → Tags. Only tagged forms are offered to agents; everything else stays invisible to them.

Create a project API key

In Project Settings → API Keys, add a key for the UAG. It stays on your server and is never given to a model.

Run the UAG next to your applications

A UAG serving a hosted Form.io project needs no license. Add UAG_ENGINES and a model key to use the Agent API.

bash
docker run -d --name formio-uag -p 3200:3200 \
  -e PROJECT=https://yourproject.form.io \
  -e PROJECT_KEY=your-project-api-key \
  -e JWT_SECRET=$(openssl rand -hex 32) \
  -e BASE_URL=http://localhost:3200 \
  -e LOGIN_FORM=https://yourproject.form.io/user/login \
  -e UAG_ENGINES=claude \
  -e CLAUDE_API_KEY=your-anthropic-key \
  formio/uag

Connect an agent

Point any MCP client at http://localhost:3200/mcp, or call the Agent API from your own code. See the options below.

Save this as docker-compose.yml

Form.io Community Edition, MongoDB and the UAG. Change every CHANGEME before you use it for anything real.

yaml
services:
  mongo:
    image: mongo:7
    restart: always
    volumes:
      - mongo-data:/data/db

  formio:
    image: formio/formio
    restart: always
    depends_on: [mongo]
    ports:
      - "3000:3001"
    environment:
      NODE_CONFIG: '{"mongo": "mongodb://mongo:27017/formio", "jwt": {"secret": "CHANGEME"}, "mongoSecret": "CHANGEME"}'
      ROOT_EMAIL: admin@example.com
      ROOT_PASSWORD: CHANGEME
      ADMIN_KEY: CHANGEME

  formio-uag:
    image: formio/uag
    restart: always
    depends_on: [formio]
    ports:
      - "3200:3200"
    environment:
      PROJECT: http://formio:3001
      ADMIN_KEY: CHANGEME
      JWT_SECRET: CHANGEME
      BASE_URL: http://localhost:3200
      LOGIN_FORM: http://localhost:3000/user/login

volumes:
  mongo-data:

Start it

bash
docker compose up -d
open http://localhost:3000     # the Form.io portal: admin@example.com / CHANGEME

Tag a form and connect

Create a form in the portal, tag it uag, and connect an agent to http://localhost:3200/mcp. Everything stays on your machine. Conversation forms run here with no license. The Agent API, workflows and Agentic Formflow need a LICENSE_KEY that includes the UAG, or a project on Form.io's hosted service (tab 1).

Get a license

A self-hosted UAG serving a Form.io Enterprise project needs a Form.io license that includes the UAG, in LICENSE_KEY: an online license with UAG servers, or an offline license with the uag option. It is the only license the UAG needs, and covers the Agent API and its engines. Ask us for a trial.

Point the UAG at your project

yaml
  formio-uag:
    image: formio/uag
    restart: always
    environment:
      # A container-to-container address: the UAG never needs a public one.
      PROJECT: http://formio-enterprise:3000/yourproject
      PROJECT_KEY: ${PROJECT_KEY}
      LICENSE_KEY: ${LICENSE_KEY}
      JWT_SECRET: ${JWT_SECRET}
      BASE_URL: https://uag.example.com
      LOGIN_FORM: https://forms.example.com/yourproject/user/login
      UAG_ENGINES: jev,claude
      TYPESAFE_API_KEY: ${TYPESAFE_API_KEY}
      CLAUDE_API_KEY: ${CLAUDE_API_KEY}

Make a form agent-ready

Four settings in the form builder.

No code. The same form keeps working for people, and gains a section an agent can fill in.

  1. Tag it uagThe UAG registers only tagged forms, so you decide exactly what agents can see.
  2. Write the criteriaA content component with uag=<task> and uagField=criteria: plain-language instructions, like onboarding a new employee.
  3. Flag the agent fieldsGive each field the agent fills the same uag property, or wrap them in a panel that carries it.
  4. Trigger itFrom a chat over MCP, the renderer plugin as users type, or a webhook to /agent/provide on submit.

Connect an agent

Three ways in, one set of rules.

Whichever way an agent arrives, it authenticates, is held to the caller's permissions, and writes only validated data.

Add the UAG to claude_desktop_config.json. The first connection opens your Form.io login, and Claude then acts with that user's roles.

json
{
  "mcpServers": {
    "formio-uag": {
      "command": "npx",
      "args": ["mcp-remote", "http://localhost:3200/mcp"]
    }
  }
}

Then ask: "I would like to add a new customer." Full guide, including claude.ai connectors.

Server-side clients exchange the project key for a token, then connect over streamable HTTP. Nothing dials back in, so the UAG can stay private.

js
import { Client } from '@modelcontextprotocol/sdk/client/index.js';
import { StreamableHTTPClientTransport } from '@modelcontextprotocol/sdk/client/streamableHttp.js';

const { access_token } = await (await fetch('http://localhost:3200/auth/token', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    grant_type: 'client_credentials',
    client_id: 'yourproject-x-token',   // formio-oss-x-admin-key on Open Source
    client_secret: process.env.PROJECT_KEY,
  }),
})).json();

const mcp = new Client({ name: 'my-app', version: '1.0.0' });
await mcp.connect(new StreamableHTTPClientTransport(new URL('http://localhost:3200/mcp'), {
  requestInit: { headers: { Authorization: `Bearer ${access_token}` } },
}));
console.log((await mcp.listTools()).tools.map((tool) => tool.name));

Every MCP tool, with its arguments.

Fill a task's fields from free text. Decisions come from a decision engine, open values from an agent engine, and nothing is saved until you say so.

bash
curl -X POST http://localhost:3200/agent/extract \
  -H 'Content-Type: application/json' \
  -H "x-token: $PROJECT_KEY" \
  -d '{"form": "claim", "task": "triage", "text": "Someone rear-ended me on Main St this morning. My neck hurts."}'
