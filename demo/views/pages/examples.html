Live demos of Agentic Forms.

Each demo runs on Form.io and the UAG on this site. Try one, then open the flow viewer beside it to see every call the agents made. Each also links the prompt that builds it in your own project.

01 · CONVERSATION FORMS

Talk to a form

Open Source compatible@formio/uag-jsagent/chat

A customer reports a problem in their own words. A service request form, embedded as a chat, asks one question at a time, maps answers onto the form's options, and submits data the form has validated once the customer confirms. The page never names a field.

Try the demo
02 · AGENTIC WORKFLOW

Hand off the review

Open Source or EnterpriseAgent: Run taskClaude

A college application triggers an admissions agent that reviews it against criteria defined in the form and records its decision. On the scholarship track, its save triggers a finance agent. Change the criteria in the form builder and the next review follows it.

Try the demo
03 · AGENTIC FORMFLOW

Forms that fill themselves

Agent API@formio/uag-jsJEV + Claude

An insurance claim wizard. The policyholder describes the loss, a decision engine chooses which steps appear, extraction prefills them as suggestions, and the UAG decides again on the server before the claim is saved.

Try the demo

Watch every agent call.

Every demo has a live view of its own runs: the call into the UAG, what the UAG asked each engine, the read-only research an engine did through MCP, and the validated save. One request id ties every leg together, all the way through the engine server.

  • You see only your own runs.
  • Each run shows the submission or Agent API call, the engine call, any research and the save.
  • Click a step to see what was sent and what came back.

Every demo is open source.

The whole site, with its forms, demo back ends and flow viewer, is one Docker Compose stack in the UAG repository. The Agentic Coding Plugin has a prompt that builds each demo in your own project.
