A claim form that completes itself.

Report an insurance claim by describing what happened. A decision engine sorts the claim in a fraction of a second and the wizard adds only the steps that apply. An agent engine fills in dates, places and names for you to check. Nothing you type is ever overwritten.

  1. You describe it"Someone rear-ended me on Main Street this morning and my neck hurts."
  2. DecisionsA decision engine answers claim type, injury and other party, each with a confidence, and ordinary Form.io conditionals turn the answers into steps.
  3. SuggestionsDate, place, vehicle and names are filled in as suggestions. Unsure answers stay open for you.
  4. Checked on saveThe claim is saved through the UAG, and its "Agent: Run task" action decides triage again before the save, so a value changed in the browser can't reroute the claim.

You always get the last word.

Pages chosen by triage

Steps appear in the rail as your description is read, each saying why. They are ordinary Form.io conditionals on the fields the decision engine answered.

Confidence scores

When triage is unsure of the claim type, a "Check our understanding" step appears. Weak fraud signals are flagged for a person, never cleared by the browser.

Your input wins

Change a suggested value, then edit the description: Agent Input reads it again and refills only what you have not touched.

Add it to your app.

@formio/uag-js connects an application to the UAG. Forms tagged uag save through the UAG, and get Agent Input from the form's own agent/extract: it streams decisions as they arrive, waits briefly on Next so conditional pages are in place, and asks once more for the pages triage added.

  • It sends the signed-in user's own Form.io token, so extraction runs with their permissions.
  • Mark fields with uag: triage; tune with uagThreshold and uagUncertainBand.
  • Measure thresholds on your own data with uag-eval before you rely on them.
Build it with your coding agent

Install the Agentic Coding Plugin and give your coding agent this demo's prompt. Its formio-uag skill designs the triage task, registers @formio/uag-js with the Next trigger, and adds the "Agent: Run task" action that decides again on the server before the save.

js
// Once, when the application starts
Formio.use(FormioUAG.UAG('https://uag.example.com', {
  onStart: () => showReading(true),
  onDone: (summary) => showReading(false),
}));

// Render the form from its Form.io URL, as before. Tagged "uag",
// it saves through the UAG; its wizard reads the description on Next.
Formio.createForm(el, 'https://forms.example.com/myproject/claim');
