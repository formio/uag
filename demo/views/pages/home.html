One definition, two readers

The form your users see is the contract your agents follow.

Form.io's renderer turns form JSON into an interface for people. The UAG turns the same JSON into context for agents: the fields, the rules, the allowed values and the instructions.

  • No retraining. Change the form and every agent changes with it.
  • No drift. People and agents are held to the same validation.
  • No glue code. Agents discover forms; you never hard-code a field.

Governed at runtime

Agents get the access of a user. Never more.

Prompts are not a security boundary. The UAG is. Every agent action passes through the same authentication, permissions and validation as a person using your application.

No model holds a write tool

Engines only answer. The UAG validates every value and writes it itself, once, so text in a submission cannot make a model change your records.

Your RBAC, unchanged

Agents authenticate through your existing Form.io login, SAML or OIDC, and act with exactly the permissions of the person or service they represent.

Auditable by design

Each decision records its engine, model, confidence and source. With Form.io Enterprise, submission revisions show who changed what, human or agent.

Calibrated, not guessed

Decision engines answer closed questions with a confidence. Below your threshold the field stays open for a person, instead of a confident-sounding guess.

Re-decided on the server

Values decided in a browser can be tampered with. The UAG decides again before saving whenever routing depends on the answer.

Change it without a deploy

Rewrite the instructions in the form builder and agents follow them within seconds. Roll back with form revisions, not retraining.

Self-hosted by design

Your data never has to leave your network.

Run the UAG next to Form.io in your own cloud, data center or air-gapped environment. Nothing needs to be exposed to the internet, and with a local model, nothing leaves at all.

  • One container on Docker or Kubernetes, beside your Form.io deployment.
  • Private by default: your applications connect out to the UAG; no public endpoint, no tunnel.
  • Local models through Ollama or vLLM, or engines isolated on their own server so model keys stay out of the gateway.
  • Enterprise ready: RBAC, FIPS-compliant deployments, form and submission revisions, stage deployments.
  • Open source under the MIT license. Read every line that touches your data.

Getting started

Running in minutes. In your environment.

Start with Form.io Open Source and the UAG on your laptop, or point the UAG at a free project on Form.io's hosted platform. Either way, it's one container.

Getting Started guide Read the docs
bash
# Point the UAG at your Form.io project
docker run -d -p 3200:3200 \
  -e PROJECT=https://myproject.form.io \
  -e PROJECT_KEY=$PROJECT_KEY \
  -e JWT_SECRET=$(openssl rand -hex 32) \
  -e BASE_URL=http://localhost:3200 \
  formio/uag

# Agents connect to /mcp; applications call the Agent API
curl http://localhost:3200/agent/capabilities -H "x-token: $PROJECT_KEY"
