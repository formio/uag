What to notice

The form is the script.

One sentence, several fields

"I'm Marcus Webb, marcus@example.com, and it's completely down" fills the name, the email and the urgency, mapped to the form's high option rather than stored as prose.

Validation the agent cannot skip

Give an invalid email and the UAG rejects it with the form's own message. The agent has to ask again; nothing invalid is ever saved.

Edit the form, not the code

Add an option or a required field in the form builder and the conversation changes within seconds. The chat code never names a field.

Build it yourself

A prompt that describes a process, not a form.

The whole application is a tool loop: send the conversation to the model, run the tools it calls against the UAG, repeat until it answers. The prompt says which tools to use in what order. Everything about service requests comes from the form.

  • The MCP client runs on your server and connects out to the UAG. No public endpoint.
  • Authenticate each user instead of a service key, and the UAG applies their permissions to every tool call.
  • Works on Form.io Community Edition. No license needed.

js
// The model calls the UAG's tools; the UAG reads the form.
const { tools } = await mcp.listTools();
messages.push({ role: 'user', content: userMessage });

while (true) {
  const response = await anthropic.messages.create({
    model, system: SYSTEM_PROMPT, messages,
    tools: tools.map((t) => ({ name: t.name, description: t.description, input_schema: t.inputSchema })),
  });
  messages.push({ role: 'assistant', content: response.content });
  if (response.stop_reason !== 'tool_use') return response;

  const results = [];
  for (const call of response.content.filter((b) => b.type === 'tool_use')) {
    const result = await mcp.callTool({ name: call.name, arguments: call.input });
    results.push({ type: 'tool_result', tool_use_id: call.id, content: result.content, is_error: result.isError });
  }
  messages.push({ role: 'user', content: results });
}
