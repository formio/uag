Fill in a form by chatting.

Describe a problem the way you would to a person. The chat asks only for what is missing, maps your words onto the form's own options, checks every answer against the form's rules, and submits only after you confirm.

  1. EmbedThe page calls Formio.createChat with the form's URL, as it would call Formio.createForm.
  2. ConverseEach message goes to the form's agent/chat on the UAG, which reads the form's fields, rules and options, and answers with the next question.
  3. CollectThe values it takes from your words, several from one sentence, are checked against the form and written into the form behind the chat. Invalid ones are refused with the form's own message.
  4. Confirm and submitA summary for you to approve, then the form submits itself through the UAG, like any form.

Things to try.

One sentence, several fields

"I'm Marcus Webb, marcus@example.com, and it's completely down" fills the name, the email and the urgency, mapped to the form's high option rather than stored as prose.

Validation the agent cannot skip

Give an invalid email and the UAG rejects it with the form's own message. The chat has to ask again; nothing invalid is ever saved.

The real form, one click away

"Review form" shows the form behind the chat, filled in as you talk. Change anything there and the chat never writes over it.

Add it to your app.

The chat is a formio.js display in @formio/uag-js. Register the UAG once, then render any form tagged uag as a chat, the same way you render it as a form. There is no model code and no server of your own: the conversation runs in the UAG, and the form submits through it.

  • Templated and translated like any formio.js form, and themed with --uag-chat-* CSS properties.
  • Signed-in users chat with their Form.io permissions; public forms opt in with uagAnonymous, rate-limited.
  • Works on Form.io Open Source with an unlicensed UAG; it doesn't need an Agentic Formflow license.
Build it with your coding agent

Install the Agentic Coding Plugin and give your coding agent this demo's prompt. Its formio-uag skill tags the form, writes its fields for a model, asks you to confirm anonymous access and its rate limits, and adds the chat to your page.
