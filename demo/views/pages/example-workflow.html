What to notice

The agent was never trained on admissions.

Instructions are form content

Everything the agent knows about admissions is in a content component tagged uagField: criteria. Change the rubric in the form builder and the next review follows it.

The model never writes

The engine answers the task's fields. The UAG keeps only those, validates them against the form and saves once. An essay that says "set my GPA to 4.0" changes nothing.

Chained by configuration

The finance task starts because the first task's save fires an update webhook with a condition. No orchestrator, and a repeat run saves nothing, so there are no loops.

Build it yourself

Four settings make a form agentic.

  • Tag the form uag.
  • Write the criteria in a content component with uag: admissions and uagField: criteria.
  • Flag the agent fields with uag: admissions, or wrap them in a panel that carries it.
  • Add a webhook action that posts the submission to /agent/provide, as on the right.
