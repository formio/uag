Running the demo locally

To run the workflow, formflow and AI Document demos on your own machine, the UAG needs a license that includes the UAG, or a project on Form.io's hosted service. The UAG this site was built against answered that it cannot run Agentic Formflow.

Start a UAG with a LICENSE_KEY that includes the UAG, or one connected to a project on Form.io's hosted service, and build the site with DEMO_UAG_URL pointing at it. Contact us for a license, or try every demo live at {{links.liveDemo}}.
